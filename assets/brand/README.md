# StrengthHub Online — brand assets

Logo files for use across the app, website, store listings and marketing.
All PNGs have a transparent background.

| File | What | Use on |
|---|---|---|
| `strengthhub-icon.png` | Chevron icon mark (512×512) | Any background |
| `strengthhub-wordmark-dark.png` | Wordmark, white text (3360×630) | **Dark** backgrounds |
| `strengthhub-wordmark-light.png` | Wordmark, dark text (3360×630) | **Light** backgrounds |
| `strengthhub-wordmark-dark.svg` | Wordmark vector, white text | **Dark** backgrounds (any size) |
| `strengthhub-wordmark-light.svg` | Wordmark vector, dark text | **Light** backgrounds (any size) |

Wordmark = "Strength" (bold) + "Hub" (brand green, italic) + "ONLINE" (small tag).
Brand green: `#7ED957` (on dark) / `#63A547` (on light). Ink: `#0A0A0B`.
The SVGs use a bold system sans-serif; outline the text for print-exact rendering.
